Project 2 – Exploratory Data Analysis

📌 Overview

This project was completed as part of my Data Analytics internship learning journey with Decode Labs.

The project focuses on Exploratory Data Analysis (EDA) to understand the dataset, identify patterns and trends, and extract meaningful insights from the available data.

🎯 Objective

The main objective of this project is to explore and analyze the dataset systematically and understand the important characteristics, patterns, and relationships present in the data.

Key objectives:

- Understand the structure and characteristics of the dataset
- Explore the available variables and their distributions
- Identify patterns and trends in the data
- Analyze relevant relationships between variables
- Generate meaningful insights from the data
- Present the findings in a clear and understandable format

🛠️ Tools Used

- Microsoft Excel

📊 Dataset

The project uses a dataset provided as part of the Data Analytics internship task.

The dataset was explored and analyzed to understand its structure, identify important patterns, and derive useful insights.

🔍 Analysis Performed

The following exploratory analysis was performed as part of the project:

- Examined the dataset and its variables
- Explored numerical and categorical data
- Analyzed relevant trends and patterns
- Compared important variables to identify relationships
- Used appropriate Excel features and analysis techniques
- Summarized the observations obtained from the analysis

📈 Key Insights

The exploratory analysis helped in identifying important patterns, trends, and observations within the dataset.

The major findings and observations are documented in the project analysis file included in this folder.
